Xiaomi `dash` 的 AOSPA 设备树
=============================================

[EN](README.md) | 简体中文

Redmi Turbo 5 Max 是一款~~拿上一代联发科旗舰芯片阉割出来的性能旗舰~~搭载正代满血联发科旗舰芯片的性能旗舰。

## 功能

- [x] 移动通信 / VoLTE
- [x] Wi-Fi
- [x] 蓝牙
- [x] NFC
- [x] 相机
- [x] GPS
- [x] USB OTG
- [x] 背部双环灯带
- [x] 指纹
- [x] 人脸解锁
- [x] 自动亮度
- [x] Dolby Atmos
- [x] Dolby Vision
- [x] 应用性能配置
- [x] 息屏显示
- [x] SELinux 强制模式
- [x] 充电
  - 快速充电
  - 反向充电
  - 充电上限
  - 旁路充电（详见设置中的说明）
- [x] 休眠与唤醒
  - 抬起唤醒 / 放下熄屏
  - 双击唤醒
  - 屏幕注意力
- [x] 加密 / 解密
